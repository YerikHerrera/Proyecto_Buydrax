================================================================================
BUYDRAX - SISTEMA DE GESTION DE RECURSOS HUMANOS
================================================================================

Buydrax es un sistema web para la gestion de recursos humanos y operaciones de
empresas del sector construccion.

El proyecto esta compuesto por:
  * Frontend: React + TypeScript + Vite
  * Backend: FastAPI + SQLAlchemy
  * Base de datos: PostgreSQL
  * Autenticacion: JWT + bcrypt (opcional Google)
  * Documentacion de API: OpenAPI / Swagger

Desde 2026 el sistema soporta arquitectura Multi-Tenant (rol EMPRESA, dominios,
soft delete, cuadrillas multi-proyecto y recuperacion de contrasena).

--------------------------------------------------------------------------------
ROLES DEL SISTEMA
--------------------------------------------------------------------------------

Buydrax contempla cinco perfiles:

  * EMPRESA      : Administrador de plataforma. Crea dominios/empresas y asigna
                   el ADMIN_RRHH de cada tenant.
  * ADMIN_RRHH   : Administracion de empleados y procesos de RRHH solo de su
                   propio dominio.
  * SUPERVISOR   : Gestion operativa de proyectos, cuadrillas y personal a cargo.
  * CONTADOR     : Procesos relacionados con nomina y contabilidad.
  * EMPLEADO     : Consulta y gestion de informacion propia.

El sistema utiliza autenticacion mediante JWT (y opcionalmente Google OAuth).
Las rutas e interfaces disponibles dependen del perfil del usuario autenticado.


================================================================================
INSTALACION Y EJECUCION
================================================================================

Para reconstruir el proyecto en un equipo nuevo se recomienda seguir este
documento o el archivo: BUYDRAX_USUARIOS_Y_GUIA_INSTALACION.txt

La instalacion se divide en tres partes:
  1. PostgreSQL y base de datos
  2. Backend FastAPI
  3. Frontend React

REQUISITOS:
  * Git
  * PostgreSQL 14 o superior
  * Python 3.10 o superior
  * Node.js 18 o superior
  * npm
  * DBeaver, pgAdmin o psql para ejecutar los scripts SQL

Nota: El proyecto fue probado durante el desarrollo con Python 3.14.3 y
Node.js 24.x.


================================================================================
1. BASE DE DATOS
================================================================================

SCRIPTS DISPONIBLES:

  * BASE_DE_DATOS_BUYDRAX_CORREGIDA.sql
    Script base (23 ENUMs, 33 tablas, datos de prueba)

  * backend/scripts/sql/2026_rol_empresa_dominios.sql
    Rol EMPRESA + tabla empresa + usuarios.id_empresa

  * backend/scripts/sql/2026_multitenant_dominio_soft_delete.sql
    Columnas dominio / eliminado_en + recuperacion_password

  * backend/scripts/sql/2026_asistencia_id_proyecto.sql
    Columna asistencia.id_proyecto

  * backend/scripts/sql/2026_cuadrillas_entidad.sql
    Tablas cuadrilla y cuadrilla_proyecto

  * backend/scripts/sql/2026_fix_cuadrilla_creado_en.sql
    Parche DEFAULT NOW() (opcional)

  * BASE_DE_DATOS_BUYDRAX_V2.sql
    Script unificado recomendado

  * SQL_RESET_PASSWORD_Admin123.sql
    Establece contrasena de prueba Admin123!

El script principal no crea una base de datos ni cambia de conexion
automaticamente. Primero debes tener una base PostgreSQL disponible y ejecutar
los scripts sobre la base que utilizaras para Buydrax.

En el entorno de desarrollo actual se utiliza:
  Base de datos : postgres
  Host          : localhost
  Puerto        : 5432
  Usuario       : postgres

Si utilizas otra base de datos, solamente debes colocarla posteriormente en
DATABASE_URL.


ORDEN DE EJECUCION (RECOMENDADO):

  Opcion A - Script unificado (preferida)
    1. BASE_DE_DATOS_BUYDRAX_V2.sql
    2. SQL_RESET_PASSWORD_Admin123.sql

  Opcion B - Scripts individuales
    1. BASE_DE_DATOS_BUYDRAX_CORREGIDA.sql
    2. 2026_rol_empresa_dominios.sql
    3. 2026_multitenant_dominio_soft_delete.sql
    4. 2026_asistencia_id_proyecto.sql
    5. 2026_cuadrillas_entidad.sql
    6. 2026_fix_cuadrilla_creado_en.sql (opcional)
    7. SQL_RESET_PASSWORD_Admin123.sql

El script de reset establece la contrasena de prueba:
  Admin123!
para los usuarios existentes (incluido el usuario plataforma@buydrax.local
del rol EMPRESA).


================================================================================
2. BACKEND
================================================================================

1. Entrar en la carpeta:
   cd backend

2. Crear y activar el entorno virtual:

   [Windows]
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1

   [Linux / macOS]
   python3 -m venv .venv
   source .venv/bin/activate

3. Instalar dependencias:
   pip install -r requirements.txt

4. Crear el archivo .env a partir del ejemplo:

   [Windows]
   Copy-Item .env.example .env

   [Linux / macOS]
   cp .env.example .env

5. Editar .env y configurar los valores correspondientes al equipo.
   Ejemplo completo:

   DATABASE_URL=postgresql+psycopg2://postgres:TU_PASSWORD@localhost:5432/postgres
   SECRET_KEY=GENERA_UNA_CLAVE_SECRETA_LARGA_Y_ALEATORIA
   ALGORITHM=HS256
   ACCESS_TOKEN_EXPIRE_MINUTES=480

   APP_NAME=Buydrax API
   APP_ENV=development
   DEBUG=True
   API_PREFIX=/api

   # Autenticacion Google (opcional)
   GOOGLE_CLIENT_ID=

   # SMTP para recuperacion de contrasena (opcional)
   # Si no se configuran, los correos se escriben en backend/logs/correos_enviados.log
   SMTP_HOST=
   SMTP_PORT=587
   SMTP_USER=
   SMTP_PASSWORD=
   SMTP_FROM=

   IMPORTANTE: No subir el archivo .env a Git. El repositorio contiene
   unicamente .env.example.

6. Ejecutar el backend (desde backend/):
   uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

   URLs disponibles:
   * API base     : http://127.0.0.1:8000
   * Swagger      : http://127.0.0.1:8000/docs
   * Health check : http://127.0.0.1:8000/health
   * OpenAPI      : http://127.0.0.1:8000/openapi.json


================================================================================
3. FRONTEND
================================================================================

1. Abrir una segunda terminal y entrar en:
   cd frontend

2. Instalar dependencias:
   npm install

3. Configurar variables de entorno (opcional):
   El frontend incluye .env.example con la conexion al backend:

   VITE_API_BASE_URL=http://127.0.0.1:8000/api
   VITE_GOOGLE_CLIENT_ID=

   Si se necesita un .env local, copiar .env.example:

   [Windows]
   Copy-Item .env.example .env

   [Linux / macOS]
   cp .env.example .env

4. Ejecutar el servidor de desarrollo:
   npm run dev

   Vite mostrara en la terminal la direccion local, normalmente:
   http://localhost:5173


================================================================================
4. ORDEN DE ARRANQUE
================================================================================

Cada vez que se quiera ejecutar Buydrax:

  1. PostgreSQL:
     Verificar que el servicio de PostgreSQL este ejecutandose.

  2. Backend (desde backend/):
     [Windows]
     .\.venv\Scripts\Activate.ps1
     uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

     [Linux/macOS]
     source .venv/bin/activate
     uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

  3. Frontend (desde frontend/):
     npm run dev

  4. Navegador:
     Abrir http://localhost:5173
